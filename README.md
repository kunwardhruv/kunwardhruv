## 🚀 Featured Projects

<details open>
<summary><b>📚 EduRAG — Class 1–12 Textbook Q&A Assistant</b> &nbsp; <img src="https://img.shields.io/badge/⭐-Showpiece-5f27cd?style=flat-square"/></summary>

<br>

> Upload any NCERT textbook PDF and ask questions — answers come **strictly from the book**, with page citations, or it tells you it doesn't know.

- 🔍 **Hybrid Search** — FAISS vector similarity + BM25 keyword search combined via Reciprocal Rank Fusion (60/40 weighting)
- 🛡️ **Two-layer hallucination prevention** — similarity threshold gate (0.25 cosine) + strict context-only system prompt at temp 0.05
- 📄 **Page-cited answers** for every response, multi-book support, Q&A history exportable to CSV
- 🖥️ Dark-themed **Next.js 14 + TypeScript + Tailwind** frontend, **FastAPI** backend

**Stack:** FastAPI · PyMuPDF · LangChain · sentence-transformers (`all-MiniLM-L6-v2`) · FAISS · rank-bm25 · Groq Llama 3.3 70B · SQLite · Next.js 14 · Tailwind CSS

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/kunwardhruv/Edurag-chatbot)

</details>

<details>
<summary><b>🤖 Autonomous Data Scientist Agent</b></summary>

<br>

> Upload any CSV → a LangGraph agent automatically runs EDA, detects the problem type, trains and tunes the best model, and explains the results in plain English — zero manual ML code.

- 🧩 **7-node `StateGraph` pipeline**: load & validate → EDA → problem detection → feature prep → model selection → hyperparameter tuning → explanation
- 🏆 Trains **4 candidate models in parallel** (Logistic Regression, Decision Tree, Random Forest, XGBoost) and auto-picks the winner by F1/R²
- 📊 **SHAP `TreeExplainer`** feature importance + Groq Llama 3.3 70B turns raw metrics into a human-readable analysis
- ⚛️ 5-tab **React 18 + Vite** dashboard (Overview · EDA · Models · Results · Explain)

**Stack:** LangGraph · scikit-learn · XGBoost · SHAP · Groq Llama 3.3 70B · matplotlib/seaborn · FastAPI · React 18 + Vite

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/kunwardhruv/Autonomous-Data-Scientist)

</details>

<details>
<summary><b>🏥 Medical AI Assistant — Post-Discharge Care System</b></summary>

<br>

> A multi-agent system that identifies patients, answers medical questions via RAG on a 1,547-page nephrology textbook, runs triage assessment, and falls back to real web search for general queries — running at zero monthly cost.

- 🧠 **LangGraph router** — 3-step decision logic (short message → web keywords → LLM classification) across 4 nodes with persistent memory
- 📚 **RAG on a 1,547-page clinical textbook** with patient-context-aware query enhancement
- ⏰ **Triage logic** that flags symptoms as IMMEDIATE vs ROUTINE follow-up, plus a kidney-specific drug interaction lookup
- 🔍 **DuckDuckGo web search fallback** for general/historical queries — no API key required

**Stack:** LangGraph · LangChain · Groq Llama 3.3 70B · FAISS · HuggingFace embeddings · FastAPI · SQLite · DuckDuckGo Search · Streamlit

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/kunwardhruv/medical-ai-assistant)

</details>
